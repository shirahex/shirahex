## How I work

I use Python and Pandas to prepare and inspect data, PyTorch for model experiments, and Flask or FastAPI to connect models to applications. For RAG work, I focus on the corpus, retrieval choices and traceable answers. Docker, Git and CI workflows help make those experiments easier to share and run.

Alongside my studies, I supervise escalations at **IO Solutions**, supporting Rogers and Fido customers in Canada. That work has developed my communication in English, problem solving and team coaching.
